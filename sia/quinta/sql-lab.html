📘 SQL e SQLite: cosa sono e perché li usiamo

1️⃣ Cos'è SQL?

SQL (Structured Query Language) è il linguaggio standard per parlare con i database relazionali. Si usa per creare tabelle, inserire dati e soprattutto per fare domande (query) ai dati. È lo stesso linguaggio usato da banche, social network, e-commerce... e all'esame di Stato! 🎓

2️⃣ Cos'è SQLite?

SQLite è una versione "leggera" di SQL. Invece di richiedere un server, vive in un singolo file ed è così compatto da poter girare dentro il tuo browser. È il database più diffuso al mondo: è dentro ogni smartphone Android e iPhone! 📱

3️⃣ Perché usiamo SQLite in questo laboratorio?

✅ Zero installazioni: funziona in qualsiasi browser, anche senza internet
✅ Perfetto per imparare: ti concentri sulle query, non sulla configurazione
✅ Le query sono identiche: quello che impari qui funziona anche su MySQL
✅ Ogni alunno ha il suo database: massima libertà di provare e sbagliare

4️⃣ Le piccole differenze (solo il 5%!)

Il 95% di SQL è identico in tutti i database. Ecco le uniche differenze che potresti incontrare passando da SQLite a MySQL (che userai all'esame).
