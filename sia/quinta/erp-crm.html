🏢 Integrazione ERP ↔ CRM

Caso d'uso: sincronizzazione anagrafica clienti via JSON
📡 API REST · JSON · HTTP POST
🎯 Scenario aziendale: L'azienda Beta Srl utilizza un CRM (Salesforce-like) per la gestione commerciale e un ERP (SAP-like) per la contabilità. Quando un venditore inserisce un nuovo cliente nel CRM, questo viene automaticamente inviato all'ERP tramite una chiamata API REST con payload JSON. L'ERP valida i dati (es. Partita IVA), crea l'anagrafica contabile e risponde con un JSON di conferma o errore.
