I COSTRUTTORI DARE VITA AGLI OGGETTI

Ogni volta che scrivi new, Java esegue un costruttore: un blocco di codice speciale che inizializza l'oggetto e ne garantisce uno stato valido. Nessuna istanza può esistere senza attraversarne uno.

01 · Anatomia

Com'è fatto un costruttore

Un costruttore assomiglia a un metodo, ma ha due regole inviolabili: si chiama esattamente come la classe e non ha alcun tipo di ritorno, nemmeno void. Clicca sui pezzi del codice per analizzarli.

LAB 01 · ESPLORA IL COSTRUTTORE
CLICCA UNA PARTE EVIDENZIATA
Studente.java
public class Studente {

    private String nome;
    private int eta;

    public Studente(String nome, int eta) {
        this.nome = nome;
        this.eta = eta;
    }
}

// Uso: il costruttore si attiva con new
Studente s = new Studente("Anna", 17);
Seleziona una parte

Esplora il codice

Clicca su una delle porzioni evidenziate nel codice a sinistra per scoprire il ruolo di ogni elemento del costruttore.

Firma this.nome new Studente(...)
Regola d'oro: se aggiungi un tipo di ritorno (anche void) davanti al nome, non è più un costruttore ma un metodo qualunque — e new non lo chiamerà mai. Il costruttore è l'unico "metodo" che non si invoca con il punto, ma con new.

02 · Il costruttore di default

Quello che Java scrive per te

Se in una classe non scrivi nessun costruttore, Java ne genera uno automatico senza parametri che porta tutti i campi al loro valore di default (0, null, false). Ma attenzione: appena ne scrivi uno tuo, quello automatico scompare.

03 · Parametri & this

      
Il problema del nome uguale

      
Dentro il costruttore, il parametro nome e il campo nome si chiamano allo stesso modo. Senza this, Java assegna il parametro a sé stesso e il campo resta vuoto. this.nome indica "il campo dell'oggetto che sto costruendo".

    

    

      

        
SENZA this · BUG

        

          

            
Sbagliato


public Studente(String nome) {
    nome = nome;  // assegna il parametro a sé stesso!
}


          

          
✗ Il campo nome resta null: il parametro "oscura" il campo. L'oggetto nasce senza nome.

        

      

      

        
CON this · CORRETTO

        

          

            
Giusto


public Studente(String nome) {
    this.nome = nome;  // campo = parametro
}


          

          
✓ this.nome è il campo dell'oggetto, nome a destra è il parametro. Ora l'oggetto nasce con il nome giusto.

        

      

    

  






  

    

      
04 · Overloading

      
Più costruttori, una sola classe

      
Una classe può avere più costruttori purché con parametri diversi (numero, tipo o ordine). Quando scrivi new, Java sceglie quello la cui firma combacia con gli argomenti. Costruisci una chiamata e guarda quale costruttore viene selezionato.

Come sceglie Java: conta il numero di argomenti, poi il loro tipo nell'ordine. new Studente("Anna", 17) usa Studente(String, int). Se nessun costruttore combacia, è errore di compilazione — non di esecuzione.
