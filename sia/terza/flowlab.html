Guida rapida

Costruire il diagramma

  • Clic seleziona · doppio clic modifica · Canc elimina.
  • Trascina un blocco per spostarlo (anche dentro rami e cicli): la barra blu mostra dove finirà. Esc annulla il trascinamento.
  • Trascina un pulsante «Inserisci» dalla barra direttamente sul diagramma per creare lì l'istruzione.
  • Nei rami vuoti puoi anche cliccare + aggiungi istruzione.
  • Ctrl+Z / Ctrl+Y annulla e ripeti.

    • Array

  • Dichiara con dimensione: v As Integer[5]
  • Indici da 0: v[0] ← 3 · Output v[2] · Input "x: ", v[i]
  • Lunghezza: v.length oppure len(v)

    • Ispettore array

  • Clicca una riga array nel pannello Variabili: si apre l'ispettore dedicato con tutte le celle.
  • Si aggiorna live durante l'esecuzione; con esecuzione in pausa puoi cliccare una cella e modificarne il valore.

    • Funzioni

  • Schede in alto sul canvas: + funzione crea, ✎ firma, ✕ elimina.
  • Firma: Nome(n:Integer, s:String) → Real
  • Blocco Chiama per invocare; Return per restituire.
  • Funzioni con tipo restituito utilizzabili nelle espressioni: x ← Media(v) + 1
  • Array passati per riferimento, scalari per valore. Ricorsione ammessa.

    • Esecuzione

  • ▶ Esegui avvia da Main · ⏭ Passo un'istruzione alla volta · gli Input arrivano nella console.

  • + - * / % ^ · stringhe: & · confronti = != < > <= >= · logica && || !
  • Integrate: abs sqrt round floor ceiling trunc sin cos tan random(n) toInteger toReal toString toBoolean len upper lower

    • Tipi

  • Integer · Real · String · Boolean e relativi array [ ]
