Che cos'è un array? (informatica in generale)

Prima di Java: l'idea di array vale per ogni linguaggio. Si chiama array, vettore, lista o table a seconda dei casi.

🏢Omogeneo

Tutti gli elementi hanno lo stesso tipo: un array di int contiene solo interi. Come un portauova: tutti gli scomparti sono fatti per le uova.

[ 6 | 7 | 5 | 8 ]

🔢Indicizzato

Ogni elemento ha un numero d'ordine detto indice. Quasi ovunque nel mondo (Java, C, JS, C#) si parte da 0, non da 1.

v[0]=6 · v[1]=7 · v[2]=5

📏A dimensione fissa

In Java la lunghezza è decisa alla creazione e non cambia più. Se servono più posti, si crea un array nuovo e si copia tutto.

v.length == 4 (per sempre)

🧠Teoria lampo

Senza array, per gestire i voti di 25 alunni servirebbero 25 variabili: voto1, voto2… voto25. Impossibile da scorrere con un ciclo!

💡 In una frase

Un array è una variabile sola che contiene tanti valori dello stesso tipo, ciascuno raggiungibile con il suo indice.

Le tre cose da sapere sempre:

  1. gli indici vanno da 0 a lunghezza − 1;
  2. la lunghezza in Java si legge con v.length (senza parentesi!);
  3. per scorrerlo si usa un ciclo for con un indice i.

Un array è una struttura dati lineare omogenea a dimensione fissa, allocata in memoria in modo contiguo. L'indirizzo dell'elemento i-esimo si calcola con base + i × dimensione_elemento: per questo l'accesso casuale costa O(1).

🔑 Le operazioni tipiche

Scansione (lettura sequenziale) · ricerca (lineare o binaria) · inserimento/cancellazione (con spostamento degli elementi, O(n)) · ordinamento · aggregazione (somma, media, min, max, conteggio).

Il prezzo della dimensione fissa: per aggiungere un elemento oltre la capacità serve creare un array più grande e ricopiare tutto (è ciò che fa ArrayList al posto tuo, con raddoppio della capacità).

Un array è un blocco contiguo di memoria: la località spaziale lo rende estremamente cache friendly (pochi cache miss nella scansione sequenziale) ed è il mattone con cui si implementano strutture più complesse: liste dinamiche, heap, tabelle hash (bucket), code circolari, matrici.

🔑 Complessità

accesso v[i] → O(1) · ricerca lineare → O(n) · ricerca binaria (array ordinato) → O(log n) · inserimento/cancellazione in posizione → O(n) per lo shift · append in array dinamico → O(1) ammortizzato · ordinamento per confronti → O(n log n) ottimo, O(n²) per bubble/selection.

⚠️ In Java

Gli array sono oggetti: la variabile contiene un riferimento. Gli array multidimensionali sono array di array (int[][] = array di riferimenti a int[]), quindi ammettono righe di lunghezza diversa (ragged array). clone() fa una copia superficiale.

Javaistruzioni equivalenti

        

    


    

      
✅Condizione corretta

        
for (int i = 0; i < v.length; i++)

        
Con < l'ultimo indice toccato è length − 1: esattamente tutti gli elementi, nessuno di più.

      
❌Off-by-one

        
for (int i = 0; i <= v.length; i++)

        
Con <= si arriva a v[length]: ArrayIndexOutOfBoundsException a run-time (il compilatore non se ne accorge).

      
🔁Scansione all'indietro

        
for (int i = v.length - 1; i >= 0; i--)

        
Si parte dall'ultimo indice e si scende fino a 0 compreso: serve per inversione, stack, percorsi a ritroso.

💻Codice generato

          
Javaper righe

            

          
📏 Dimensioni

            
m.length = 4 (numero di righe) · m[0].length = 5 (numero di colonne) · celle totali = 20

        

        

          
🧠Come funziona davvero

          
Una matrice è una tabella: per indicare una cella servono due numeri, la riga e la colonna. m[1][2] = «riga 1, colonna 2» (sempre partendo da 0).

            
💡 Regola
Due cicli annidati: l'esterno sceglie la riga, l'interno scorre le colonne. Per ogni riga il ciclo interno riparte da capo.

          
In Java int[][] m = new int[3][4] crea un array di 3 riferimenti, ciascuno a un array di 4 int. Per questo le righe possono anche avere lunghezze diverse (ragged array).

            
int[][] m = new int[3][];m[0] = new int[4];m[1] = new int[2];   // lecito!m[2] = new int[5];

            
⚠️ Errore classico
int[][] m = new int[3][]; m[0][0] = 1; → NullPointerException: la riga 0 non è ancora stata allocata.

          
Scansione per righe = accessi contigui → ottima cache locality. Scansione per colonne salta di m[0].length celle a ogni passo → molti più cache miss. Stesso numero di operazioni, velocità reale molto diversa.

            
🧮 Complessità
Su matrice n×m ogni scansione completa costa O(n·m). Moltiplicazione di matrici quadrate n×n: O(n³) con l'algoritmo classico (Strassen scende a O(n^2.807)).

🧭Quale struttura scelgo?

        

          
        

      

      

        
📚Glossario

        
array / vettore
Struttura dati lineare, omogenea, a dimensione fissa, con accesso tramite indice.

        
elemento / cella
Uno dei valori contenuti: v[3] è il quarto elemento.

        
indice
Numero intero che identifica la posizione: da 0 a length − 1.

        
length
Campo (non metodo!) che restituisce il numero di elementi; è immutabile dopo la creazione.

        
scansione (traversal)
Visita di tutti gli elementi, di solito con un ciclo for.

        
for-each
for (int x : v) — legge gli elementi senza indice; non permette di modificarli.

        
ArrayIndexOutOfBoundsException
Errore a run-time per indice negativo o ≥ length.

        
accumulatore / contatore
Variabili esterne al ciclo che raccolgono somma, minimo, numero di occorrenze…

        
ordinamento (sort)
Riordino degli elementi: bubble, selection, insertion (O(n²)); merge, quick, Arrays.sort (O(n log n)).

        
ricerca lineare / binaria
Scansione completa O(n) vs dimezzamento dell'intervallo O(log n) su array ordinato.

        
matrice / array 2D
int[][]: array di array; m.length = righe, m[i].length = colonne della riga i.

        
copia superficiale / profonda
clone() duplica solo il primo livello; per array 2D o di oggetti serve clonare anche i livelli interni.

        
cache locality
La contiguità in memoria rende la scansione per righe molto più efficiente di quella per colonne.

        
autoboxing
Conversione automatica int ↔ Integer: necessaria perché ArrayList contiene solo oggetti.
